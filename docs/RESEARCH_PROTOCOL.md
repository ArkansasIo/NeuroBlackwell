# Research Protocol and Data Governance

## Evidence classes

Every project artefact should be labelled as one of:

- **Synthetic:** generated by code, a random process, or a mathematical model.
- **Empirical:** measured from a documented experiment or public dataset.
- **Derived:** processed from another identifiable source.
- **Illustrative:** a diagram, toy model, demo, or explanatory visualization.

Do not mix classes in a way that implies synthetic outputs are empirical observations.

## Minimum experiment record

Record the following when applicable:

| Field | Meaning |
|---|---|
| `experiment_id` | Stable unique identifier |
| `model_name` / `model_version` | Implementation used |
| `created_at` | UTC timestamp |
| `seed` | Reproducibility seed, or null when unavailable |
| `parameters` | Full effective configuration |
| `input_sources` | Dataset IDs, URLs, licences and versions |
| `preprocessing` | Transformations and coordinate conventions |
| `output_status` | Synthetic, empirical, derived, or illustrative |
| `limitations` | Known simplifications and failure modes |

## Neuroimaging and atlas data

Before using MRI, histology, cell-atlas, connectomics, or other human-derived materials:

1. Confirm permitted use and licensing.
2. Preserve source URL, citation, release/version, and retrieval date.
3. Preserve coordinate system, units, orientation, voxel spacing, and transforms.
4. Document preprocessing and any lossy conversion.
5. Remove or protect identifying information and follow applicable consent and governance requirements.
6. Do not fabricate missing measurements or metadata.

## Learning benchmark

Synthetic questions can support software tests and exploratory learning workflows, but their scores are not validated IQ estimates, diagnostic outputs, or evidence of educational efficacy. Keep accuracy, mastery, retention, response time, transfer and error category as separate measures. Human use requires appropriate review, accessibility testing, and validity studies.

## Model claims

Describe neural components by their actual implemented mechanism (for example, simplified leaky integrate-and-fire dynamics). Avoid claiming physiological accuracy, consciousness, medical utility, or equivalence to living neural tissue without independent evidence.
