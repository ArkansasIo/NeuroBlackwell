# Upstream neural and brain-computing projects

## Cortical Labs

- CL SDK: https://github.com/Cortical-Labs/cl-sdk
- CL API documentation: https://github.com/Cortical-Labs/cl-api-doc
- Developer documentation: https://docs.corticallabs.com/

The CL SDK is an upstream local simulator for developing applications against the CL API. It is distinct from the educational NeuroBlackwell simulator.

## Integration policy

Integrate upstream projects through adapters or documented dependencies. Record tested versions and provenance. Preserve upstream licences and attribution. Do not claim simulator equivalence to living neural cultures without validation.
