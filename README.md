# Synthetic Human Brain Program

A modular research platform for computational neuroscience, synthetic neural simulation, brain-inspired learning benchmarks, mathematical computing, biological-computing research, procedural environments, and reproducible experiments.

## Research status

This repository contains educational and computational models. Simulated results must not be represented as measurements from living neural cultures or as a literal copy of a human brain. MRI, histology, connectomics, and cell-atlas data must retain source, licensing, coordinate-system, and preprocessing metadata. Synthetic question sets are practice benchmarks, not validated clinical IQ tests.

## Components

- Educational neural and synthetic-tissue simulation
- Anatomically informed 3D brain visualization scaffold
- MRI/atlas research notes and data-ingestion foundations
- Modular mathematics engine and reproducible experiments
- Adaptive learning benchmark across kindergarten through graduate/research levels
- Question schemas, scoring, mastery, memory hooks, and workbook generation
- MySQL/PHP research toolchain and REST/WebSocket API
- Integration references for Cortical Labs, Brian2, NEST, NEURON, Nengo, Norse, SpikingJelly, snnTorch, and BindsNET
