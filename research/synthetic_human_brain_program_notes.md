# Synthetic Human Brain Program — research and naming notes

## Project name
The user-facing project name is **Synthetic Human Brain Program**. The historical repository slug is currently `ArkansasIo/NeuroBlackwell`; changing the GitHub repository slug requires the repository rename/admin API, which is not exposed by the connected GitHub actions used in this session.

## Scientific scope
This is a computational research and education platform. Its simulated neurons, brain regions, learning scores, and generated questions are models or synthetic data unless explicitly linked to a documented empirical dataset. It is not a complete digital copy of a human brain and its benchmark is not a clinical IQ test.

## Learning benchmark
- Curriculum levels: kindergarten, elementary, middle school, high school, college, university, graduate/research.
- Record subject, domain, skill, difficulty, answer, prerequisite skills, and provenance for each item.
- Track accuracy, concept mastery, retention, transfer, response time, and error category separately.
- Avoid presenting a single score as a validated IQ estimate.
- Question banks are synthetic practice material and require review before educational deployment.

## Elementary set 1
The companion `elementary_set_01.json` contains 20 synthetic items spanning arithmetic, reading, science, social studies, logic, computing, arts, music, health, environmental science, and reasoning.
